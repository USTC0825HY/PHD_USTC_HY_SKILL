# 表达问题索引与处理边界

沿用上游规则编号便于历史对照。每一项都是检查线索，不是作者身份分类器或必须改写的阈值。用户授权、事实保护和目标语体优先；有效原句可以保留。不要为了“具体”补数据、权威出处、个人经历或产品能力。

| 编号 | 检查对象 | 处理边界 |
|---|---|---|
| 1 | 过度拔高意义 | 把评价与原稿已有依据对齐；正式语体也不需要无依据的拔高。 |
| 2 | 空洞关注/强调 | 检查强调对象是否具体；有真实优先级时保留。 |
| 3 | 时代背景开场 | 删与论点无关的背景；有范围或时间条件时保留。 |
| 4 | 尾巴式总结 | 避免重复结论；不删除限定条件。 |
| 5 | 模糊权威归因 | 核查已有引用或指出未核实处，不编机构、人名、年份。 |
| 6 | 挑战与展望 | 保留实际风险与待验证事项，压缩模板段。 |
| 7 | 抽象词过载 | 逐词看是否有实义，不能按词表一律删“赋能”等词。 |
| 8 | 意象堆叠 | 看意象是否连贯和服务语体，不强制去掉文学修辞。 |
| 9 | 同义词轮换 | 同一对象保持指称清楚，技术术语不随意换名。 |
| 10 | 不仅…更… | 核对递进是否成立，保留真实的并列与递进。 |
| 11 | 的字堆叠 | 拆长定语以提高可读性，不以数量判错。 |
| 12 | 进行+动词 | 能直接用动词时可简化，技术/流程描述可以保留。 |
| 13 | 从…到… | 核对起止对象的对应关系，不重写成输入没有的过程。 |
| 14 | 性后缀 | 区分术语和空泛名词化；线性、稳定性等按实际含义保留。 |
| 15 | 化后缀 | 同样检查实义，不误删量化、数字化等领域概念。 |
| 16 | 破折号补注 | 保留澄清、插入、转折功能；重复解释才考虑压缩。 |
| 17 | 中英括注 | 保留有用首释，删除无用反复；见 whitelists.md。 |
| 18 | 数字列点 | 步骤、比较、检查表可以列点；叙事按逻辑分段。 |
| 19 | 空洞枢纽句 | “说到底”等没有增加信息时可省；保留原有犹疑和必要限定。 |
| 20 | 列表预告 | 已有标题或上下文足够时省略预告，不强制删除导航。 |
| 21 | 成语堆叠 | 核对准确性与语体，常规公文表达也要有实际含义。 |
| 22 | 机械排比 | 保留有意的韵律与有效并列，不按句数判错。 |
| 23 | 总分总模板 | 选择适合内容的结构，摘要与报告结论不因重复形式被删。 |
| 24 | 装饰性格式 | 按交付媒体和用户要求保留必要加粗、图标或emoji。 |
| 25 | 破折号频率 | 频率仅提示检查；按标点功能决定是否修改。 |
| 26 | 客服式语气 | 结合交往关系调整，不把真实服务消息强改成冷硬命令。 |
| 27 | 过度迎合 | 去掉无依据赞美，保留礼貌与原作者真实评价。 |
| 28 | 能力/时效说明 | 保留会影响结论的真实限制，省略无关套话。 |
| 29 | 空洞积极结尾 | 结论应由正文支持；作者明确表达的希望不自动删除。 |
| 30 | 冗余书面短语 | 压缩不承载信息的套层，保留因果、范围、时态。 |
| 31 | 模糊限定 | 区分口头填充与证据不确定性；推测不能改成证实。 |
| 32 | 号召句 | 看是否符合用户用途和品牌语体，不强制保留或删除。 |
| 33 | 语序问题 | 见 syntax.md；自然有效的被动句和后置原因可保留。 |
| 34 | 连接词空转 | 核对因果、转折、递进是否真实，不按密度配额改。 |
| 35 | 句长与节奏 | 按信息组织调整长短，不为节奏补新事实或个人插话。 |
| 36 | 专名重复 | 指代明确时可简化，技术安全或多对象场景保留全名。 |
| 39 | 物理动词喻思考 | 比喻成立且符合语体时可用；生硬直译可改清楚。 |
| 40 | 形容词+冒号 | 如“结论很清晰”可直接陈述结论，但不禁该句式。 |
| 41 | 抽象主语 | 已有具体对象时可显明；不得编造行动主体。 |
| 42 | 英文与译名 | 遵守领域、项目和读者约定，见 whitelists.md。 |
| 43 | 占位例子 | 从已有材料提炼；缺信息时保留占位或指出，不编人名/数字/经历。 |
| 44 | 默认列表骨架 | 按内容顺序选段落/列表；必要操作步骤应保留。 |
| 45 | 表格使用 | 适于映射比较的数据可保留表格；叙事转段落不改变事实。 |
| 46 | 格式标记残留 | 按目标媒体转换可见格式，保留代码和引语原貌。 |
| 47 | 引用与URL | 核查来源；访问失败不证明不存在；跟踪参数不证明作者身份。 |
| 47b | 占位与匿名信息 | 区分待填字段、匿名化和示例；不编具体值，不强制附报告。 |
| 48 | 否定对举 | 保留真实辨析，压缩空泛拔高；不按工整程度判作者身份。 |
| 51 | 第二人称与对象 | 按真实读者关系选你/您/用户等，不强制改成第二人称。 |

## 核查引用与缺失信息

若任务需要验证引用，查原文或正式页面，记录实际核实范围。打不开、未搜到或 DOI 错配只能支持相应记录，不能直接证明论文不存在。没有依据时不能改成“有研究表明”掩盖出处问题。

URL 中可移除的跟踪参数可以按任务清理，保留必要查询参数与资源身份。占位信息若影响交付，可简短指出待补处；用户要摘要时再说明处理方法。已授权删除无用占位行时可以删除，不能自行填入真实地址、金额或人物。
