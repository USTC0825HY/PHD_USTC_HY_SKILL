# 文字与局部电路图

## 工程语体

使用简短陈述句，描述对象、连接、参数和缺口。正文不写“用户”“AI分析”“本助手”“不猜测”“为了便于您”等制作过程文字。追溯记录可以保留确认来源和日期，但不挤入显示网名。

| 避免 | 使用 |
| --- | --- |
| 无温控板原理图（填在测点栏） | 温控板接口脚位尚未确认。 |
| 归属已澄清，网名具有误导性 | 接口连接误差检测板，网名保留WKQD前缀。 |
| 禁止固定乘2/3 | 二极管压降尚未确定，当前参数不足以计算源端电压。 |
| 不跨接猜测 | 已确认至底板X17.86，来源板对应脚位尚未确认。 |
| 资料：pstxnet.dat L519/1492 | 正文写具体电路连接；路径和行号保存在追溯记录。 |
| N16781852 | 已核实的接口名，或“误差检测板D13.2/3”；不能编造源板网名。 |
| 采集已打通（仅网表核对） | 设计路由已核对。本次未进行实物导通及采集测试。 |

不要求全文删除“待确认”，也不以文风判断作者身份。润色不能改型号、网名、数字、极性、否定和证据强度。网名里的GS/CW可能是历史层级名，不能为了统一命名而改动原始标识。

路由箭头写 `->`；并联写“R915并联R916”。只在说明字段替换 `||`、`∥`、`‖`，不全文件替换代码、公式或引用原图。自动网号仅从展示字段隐藏，内部追溯字段保留。

## 截图

截图目的为解释测量电路。按公共采集、分流/放大、分压、霍尔和具体来源板分组，放简表下方，纵向排列。每张尽量只涵盖一个可解释的局部链路；大电路可拆为相邻局部图，附同一组编号。

保留信号名、位号、阻值、引脚和参考地。确认裁切没有截断关键输入/输出，避免整页缩小后文字无法辨认；不能只截一整个连接器代替源头电路。

图题格式：`电源板 +5.5 V支路电流采样（0x11）`。其下一行写原理图文件名和页码；有版本差异再加一句。示例：`公开版结构参考。R339等9只电阻装配状态按本次记录。`

图内TSD文字不涂改。当前装配确认按具体位号旁注，不暗示截图已变为内部版。缺少源板电路时可放底板的局部转接图，题目必须写“接口转接”，不能写“原始测量电路”。

保留宽高比，源图像素不足时重新渲染原PDF，不通过AI重绘或插值编造标注。图题、地址、文件和页码逐张对应；图像显示清楚不等于路由正确。
