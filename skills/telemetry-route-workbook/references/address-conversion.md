# 地址与换算

## 地址

从当前XPR确定有效RTL和XDC，核对地址控制字的各位到实际MUX A0…An，查清EN、WR/锁存、复位、选择编号与芯片输入脚。接口位序、显示HEX和物理通道号分别记录。表内地址作为文本标识，按数值排序，保留前导零。

级联MUX应画最小连接图，列出所有物理S输入、级联入口、接地输入、外部源输入及未连接输入。选路记录按可独立选择路径计数；同一源的重复地址可保留但要显式标为别名，不能默默删掉。未使用的地址位写“不影响当前路由”，不能暗示其必须为0。

代码静态核对还应区分选择更新、地址稳定时间、开始转换、首帧有效性和数据接受条件。地址位对应正确不代表首次采样已稳定。只报告当前任务范围，不擅自修复RTL。

## 分级换算

1. 原始读数：位宽、码制、字节/位序、有效位来源。
2. 有符号码：补码转换与位宽一致；偏移二进制另用对应规则。
3. ADC输入：参考电压、输入范围、VIN/SENSE或差分定义。正满量程通常比端点少1 LSB。
4. 遥测接口：ADC前放大/衰减、偏置和极性。
5. 源端物理量：分压、采样电阻、放大器增益、传感器灵敏度与标定。

每级写单位和成立条件。电路输入阻抗、串联电阻及后级负载可能改变分压，不能看见两只电阻就默认单位增益。二极管压降、传感器零点或阻值未知时只给支持的中间电压。

标称参考、计算参考与实测值独立记录。显示可简写“Vref：5 V”，参考来源和标称属性另记；通用模板不预填5V。改参考值时同步公式、示例、LSB和说明，不能仅改标题。

## 电流、负载与符号

码值统一用D；原始帧另记D_raw，先提取有效位并解释码制，再进入公式，不能重复右移。通道编号与完整串行命令分别说明。多链路同号地址用chain_id区分，不把不同ADC的0x05合并。

采样电流：ΔV=I×Rs；AD620的G=1+49400/RG；Vout≈G×Rs×I；k=V_ADC_IN/Vout；I≈V_ADC_IN/(k×G×Rs)。Rs是并联后的采样等效电阻，RG是增益电阻，G与k均无量纲。单级输出串联Rout及对地RL时k=RL/(Rout+RL)；复杂负载按实际网络推导，不能默认k=1。分压反算倍率m=V源/V_ADC_IN，不与k混用。

主式可按明确约定忽略零点，但霍尔器件固有零点VH0不能因此删除：I=(V霍尔−VH0)/SH。SH、温阻曲线或RF功率标定缺失时只输出已知电压／阻值。二极管保留有方向的压降项；同源参考通道说明只能主要反映比例。

每路先列符号对应的位号、数值、单位和极性，再列完整式、数值近似式及仅含D的最终式；中间使用未舍入值。只有G×Rs×k≈1 V/A时才写“I（A）≈V_ADC_IN（V）”。未知参数保留，不为获得只含D的公式而赋值。

## YCQD案例的数值测试

仅对已选定的16位补码、5 V参考模型：

`D = D_raw`（D_raw < 32768），否则 `D = D_raw - 65536`；`V_ADC_IN = D * 5 / 32768`。

| HEX | D | V_ADC_IN/V |
| --- | ---: | ---: |
| 0x0000 | 0 | 0 |
| 0x0001 | 1 | 0.000152587890625 |
| 0x4000 | 16384 | 2.5 |
| 0x7FFF | 32767 | 4.999847412109375 |
| 0x8000 | -32768 | -5 |
| 0xC000 | -16384 | -2.5 |
| 0xFFFF | -1 | -0.000152587890625 |

1 LSB = 152.587890625 µV。此表不证明ADC前端增益或源端换算。新器件重新核对数据手册，不能套用这些数字。
