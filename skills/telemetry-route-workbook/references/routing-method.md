# 遥测路由专用补充

先读`fpga-board-signal-chain-closure/references/trace-and-evidence-method.md`（同级技能目录下），通用板卡身份、逐段取证、跨板配对和装配规则以该文件为准；精确网表查询交给`fpga-orcad-xdc-pipeline`。

遥测默认从采集端反查：

`MUX/ADC输入脚 -> 板内串联元件 -> 采集板接口 -> 底板入口/网络/出口 -> 来源板接口 -> 调理电路 -> 原始测点`

该顺序是查证顺序，不是电流方向。板内通道不添加底板段；未知跨板边界用独立缺口，不把候选连成通路。

终点按被测量确定，不能停在接口输出：

- 电源电压：实际源网、上下臂、测量节点、参考端与负载。
- 采样电流：采样电阻两端、并联等效值、放大器输入极性、增益及输出负载。
- 霍尔：一次侧支路、输出、固有零点与灵敏度。
- 反馈／检波：具体器件输出脚、串联元件和接口；没有功能或标定证据不补造主从、快慢环或功率。
- 温敏：传感器、固定电阻、激励电源与ADC负载；没有温阻曲线不换成确定温度。

保持真实源板网名、底板网名、采集输入网名三层身份。已确认接口别名可以展示；自动网号只留取证记录，无别名时使用板卡＋器件脚。

对CW/GS选源、级联入口与地参考分别建记录，逐只核对选源电阻；源端物理量、ADC输入、数字通道和应用条目数量分别统计。转换公式另见`address-conversion.md`，界面呈现另见`workbook-layout.md`。
