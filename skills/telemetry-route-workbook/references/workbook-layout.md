# 表格布局与保真

## 两种视图

各视图服务不同阅读任务，使用同一映射记录，通过稳定route_id关联；已知采集端以chain_id＋规范地址检查唯一性。当前行坐标只是显式绑定，不是永久身份；排序后重新核对信号和板卡字段。每张表声明自己的覆盖集合，不要求简表与详细表条数相同。

新建表一“遥测简表”：采集板接口实际网名、地址HEX、各级MUX选择、来源板卡、底板网络名称/接口坐标、来源板接口网络名/引脚、原始源网名/测点、物理意义及换算。

新建表二“地址与物理意义”：地址HEX、各级MUX选择、采集板接口实际网名、来源板卡、完整反向信号链、换算关系。

MUX列数随实际结构变化，不固定D43/D26。简表不放复杂路由。公共参考、接口归属和级联计数放表前，不每行重复。现有表格遵守其列结构和本次授权，不因为默认模板而增列、删表或重排序。

## 分类与两列写法

需要分类时使用：采样电阻电流、霍尔电流、电流监测（未闭合）、电源电压、反馈电压、射频检波电压、温敏电阻相关。分类不改变原核对状态，也不暗示温度／功率已标定。是否增列以当前授权为准。

“物理意义”按监测量、正方向、实际器件参数、参考网络、近似条件分行；每个非公共公式符号在此有定义。“换算关系”按D到ADC电压、ADC电压到物理量、数值系数式排列，一行一个公式。表前集中放码制、I/V公共关系及地址说明，各行不重复长段过程文字。

跨板“遥测信号名称”统一三行：源板接口网络名、底板接口网络名、输入遥测模块网络名；必要时在源板行附接口脚位。板内信号维持实际输入网名，不补造底板段。真实源板网名与底板名不互相冒充。

已有22号等人工字号优先保留。参数／公式列左对齐、顶端对齐并自动换行；类别、地址和状态居中。只能在授权范围调整行高／列宽，不用空格凑齐、不缩小字号塞文本。筛选隐藏记录仍计入覆盖；临时展开检查后恢复筛选，不恢复此前删除的记录或列。

## 长路由

单格按“【采集板内】、【底板转接】、【来源板内】、【原始测点】”分段，段间空一行。同名位号带板卡前缀。段标题、跨板节点及最终测点局部加粗，不能整格全粗代替层次。未知段单独陈述，不画连续箭头。

## 编辑前后

编辑前记录工作簿SHA-256、表名、表头、原生Table名/范围/列名、筛选条件、冻结、行列尺寸、合并、公式、富文本和图片哈希/锚点。授权变更以单元格及结构项白名单表达，禁止把整个sheet设为允许变化来规避保真。

按当前spreadsheets技能选用支持的编辑方式。图片、富文本或原生Table导出存在局限时先在副本验证，限定处理受影响的OOXML部分，不用一轮无差别重存丢失对象。不要复用假设sheet1就是第一页的临时脚本；必须解析workbook关系定位实际XML。

插列后检查：

- 数据、原生Table列数/列名与可见表头一致；表头无空值、无白底白字。
- Table ref、autoFilter ref、独立筛选、冻结点、合并区域及公式引用覆盖新列。
- 旧列内容与富文本随列迁移，已有图片锚点按此次布局意图保持或移动。
- 表头行不得落入通栏合并区；标题合并不跨入数据表。

文本修订只允许目标值变化，样式、图片、公式应保持。结构重排用明确的旧/新坐标映射检查移动，不把移动误判为删除后新增。保存后重新打开，再检查Table与实际单元格；成功导出不能替代这一检查。
