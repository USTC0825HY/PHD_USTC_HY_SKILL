# Academic Paper Analysis PPT

## Workflow

1. Read the paper or extracted Markdown, then identify problem, contribution, method, data, results, limitations, and relevance.
2. Build a talk narrative: why the paper matters, what was done, what evidence supports it, and what can be reused.
3. Redraw key mechanisms or workflows as editable diagrams; crop figures only when the source figure is the object of discussion.
4. If the paper connects to MAROC or hardware development, map it to local tasks without overclaiming implementation readiness.
5. Use existing academic PPT skills for general academic style when the task is not MAROC-specific.

## Default Sections

Background, paper question, method, experiment setup, key results, limitations, project relevance, discussion questions.
