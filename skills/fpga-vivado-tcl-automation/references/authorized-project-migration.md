## 基线与复制

1. 核实本地规则、Git 未提交状态、当前 XPR 和目标工具版本。正常保存并关闭占用工程的 GUI；不强杀进程，不仅凭旧 PID 判断当前占用。
2. 记录 XPR、全部维护输入与配套数据的绝对路径、大小、时间、SHA-256、活动角色和去向。按真实登记与依赖确定输入；来源元数据中的历史路径单独记录。基线数量来自当前证据，不沿用其他工程的统计。
3. 生成完整旧路径→新路径映射。先复制至最终位置，逐文件核对哈希，保持冻结 RTL/TB、第三方源码正文及单文件多模块边界。共享源只留一个活动权威副本；未使用参考输入放 `.srcs/reference`，不递归登记。
4. 活动 XCI/XCIX 使用目标版本支持的导入流程；XCIX 按容器处理，核验根 XCI、端口、版本、配置、初始化数据、OOC 属性。保存约束 UsedIn/启用/处理顺序和实现钩子。通过 Vivado 更新登记，不手改 XPR XML，不升级 IP。

- 重开 XPR 核对 top/part、活动文件、逻辑 IP、约束/钩子、编译顺序；静态检查、语法、RTL elaboration 分别列出结果。OOC stub 展开不证明 IP 内部实现通过。
