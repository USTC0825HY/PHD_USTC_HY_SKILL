## 1. 开篇四要素（题名后、第一章前，共 5 段）

1. 题名（16pt 加粗居中）：`电性加强件测试结果(更新至YYYYMMDD)`——日期为半角括号"更新至"，可与文件名日期不同步。
2. 空段一段。
3. `测试板卡：电性加强件。`或`测试板卡：鉴定件。`——按本次对象填写，句号结尾。
4. `注：`
5. 每板卡一行改焊状态说明，模式 `板卡代号-板名 + 空格 + 状态说明`：
   - `数字锁定板-SZSD 进行了改焊接前后两轮测试-有改焊接前后的结果对比`
   - `延迟驱动板-YCQD 直接测试了改焊接后的状态，后文不再说明`

## 3. 小节内顺序（固定）

```
1) 测试/分析方法：……
2) 指标要求：……
   [结果表格]
3) 结果说明：……
   [图 × N（小节末尾）]
```

- **图永远在小节末尾**（结果说明之后）；表格紧跟指标要求段。
- 标签规范写法：`测试/分析方法：`／`指标要求：`／`结果说明：`（全角冒号）。遗留变体（`测试方法：`、`分析方法测试链路：`、`改焊接后复测：`作结果标签、指标要求无冒号直述等）在既有报告中不改，新写小节一律用规范写法。
- 小节无数据时保留标题占位（如 `隔离度-未测，待补充`、`噪声-待重测`），不写空三段式。
- 指标要求缺失写 `未提供`；无正式限值写 `未提供正式指标限值，按…评价`（见范本 5.1/5.2/8.1 三种句式）。

## 4. 表格规范（在 format-contract 基础上补充）

- 表头深蓝 1F4E79 白字加粗；限值直接写进表头括号：`INL LSB要求≤20 LSB`、`SFDR>65 dB`、`1 Hz（＜−50 dBc/Hz）`、`JG18(>40 dB)`。
- 状态列：AD2208 用 `状态`，DA766 用 `改焊情况`；改焊对比规则全部遵循 rework-comparison-style.md（改焊后行在前蓝底、改焊前行红底灰字、接口列 vMerge、未复测单行 `—`/`改焊前`）。
- 二级表头五种场景（第 1 行逻辑列 + 第 2 行展开）：DAC 码值逐码展开（DA9726/DA766 输出电压）、频点分组（GTH 功率/秒稳 ×4 频点）、RF 频段分组（100MHz/20MHz × 功率+谐波抑制）。
- 隔离度矩阵表：行=驱动通道（`驱动/安静` 表头），对角填 `——`，不适用填 `/`。
- 表格行不跨页（cantSplit）、表头重复（tblHeader）。

## 5. 图规范

- 题注模式：`图N 电性加强件 器件名 接口名：内容`（如 `图33 电性加强件 AD9245 X1G：输入功率刻度与99%临界满量程`）；无接口名时省略（TLV2548 映射图）；变体无冒号（INL/DNL 类）为遗留允许。
- 图上文下；题注紧随图片段（独立居中段）。
- 编号：范本前 32 张为 SEQ 域、之后为纯文字；**新图一律纯文字续号**（接全文最大号，不重排既有号，不引入新 SEQ 域）。
- 尺寸分档（宽为主控，高按内容）：

| 图类 | 宽×高 (cm) |
|---|---|
| 刻度/拟合图 | 15.35 × 9.0～9.23 |
| 频响/带宽图 | 14.94～15.35 × 9.0～9.24 |
| 噪声 ASD 图 | 13.5～15.35 × 9.0～10.24 |
| 频谱截图（GTH/RF） | 13.93 × 10.5 |
| 秒稳图 | 14.63 × 8.37 |
| 长条/矮截图（遥测/计数器） | 15.35 × 自适应（2.9～6.6） |

- 需要重新生成分析图时路由至 laser-electrical-data-analysis 并遵守当前 MATLAB 工程规则；以下为历史导出约定，不由DOCX编辑脚本重算或导图。MATLAB 出图：白底黑字浅灰网格（共享导出路径），`print -dpng -r150` + `PaperSize=[15 10]`（2250×1500）；禁止 exportgraphics 直接导出。

## 6. 备注段五类句式（位置固定）

1. **章级口径段**（章标题下第一段，无标签，首行缩进）：`本章XX测试均为YYYYMMDD改焊接后采集口径，无改焊接前对照数据。`
2. **节级口径段**（指标段后、表前）：`以下列写的XX均为改焊后的结果。`
3. **表后换算备注**：换算系数/方法说明（如 `板级截止频率=实测×83/33≈2.5152；…无需修正。`）。
4. **表后测量局限注**：`注：延迟含测试线缆与测量链路影响；…未做重复测量统计。`
5. **标题内状态标注**：`-待重测`、`-未测，待补充`、`-改焊接后复测`、`-复测完成`、`-复测（YYYYMMDD）`。

## 7. 结果说明句式

- 判定词放句末：`…，满足。`／`…均满足指标。`／`…均不满足指标`／`正式状态为暂不能判定，待…确认后补充判定`。
- 区间：全角 `～` 连最小~最大，改焊前对照括注其后：`81.7～88.5 nV/√Hz（改焊前83.2～86.8 nV/√Hz）`；逐路列表式：`INL为JG15 46.98、JG17 13.24、…LSB`。
- 复述限值：`均低于300 nV/√Hz限值`、`均满足≤10 μV/√Hz要求`。
- 主语以路数开头：`五路…`／`四通道…`／`八通道…`。
- 不确定口径副句保留：`供参考`、`未扣除PICO/DAC本底`、`均为未括住外推`。
