# 加强件测试结果格式契约

> 本契约覆盖页面/字体/基础表格色。完整格式（章节顺序、小节内顺序、图表、备注句式、改焊对比触发、数据溯源附录）以 [report-format-spec.md](report-format-spec.md) 为最高权威；两者冲突时以后者为准。

默认范本：F:/01_Laser/0_20260727_513test/03_CW测试/01_Documents_文档/02_Test_Reports_测试报告/02_jiaqiang/电性加强件 SZSD_YCQD_20260927.docx；电性加强件 SZSD_YCQD_20260920.docx 为改焊前基线参考。
只提取通用结构与排版，不固化该板次数据。用户指定的新范本和最新编辑文件优先，不自动选 backup 文件。

## 页面和结构
新建报告默认 Letter 21.59 × 27.94 cm，四边 1.4 cm，页眉页脚距离 0.76 cm。无封面、目录、运行页眉及分节页码。
题名后简写测试对象、更新日期和影响结果的板卡状态。一级为板卡/器件，二级为指标。
每项顺序：测试/分析方法 → 指标要求 → 结果表格 → 结果说明 → 对应图片及题注。
要求缺失写“未提供”。文末设数据溯源附录；不强制前置汇总表、额外追溯章节、待测汇总或“尚未测试内容：无”。

## 字体和编号
核对范本样式、直接格式及 docDefaults 后，采用：题名宋体16 pt加粗居中；正文宋体12 pt；表格/题注宋体10.5 pt；一级标题微软雅黑15 pt，二/三级微软雅黑12 pt。标题黑色。
英文、数字、单位和信号名统一 Times New Roman。eastAsia 与 ascii/hAnsi/cs 分别显式设置，清除冲突主题字体；保留数学字体和公式结构。
正文默认1.5倍行距、首行两字、段前段后为零；表格、图片和题注为单倍行距、段前段后为零。表格、图片、题注缩进为零。局部编辑继承目标中文格式，不整本替换。
标题使用真实多级列表 %1.、%1.%2、%1.%2.%3，禁止手输编号。标题与后续内容同页。具体格式以 scripts/result_summary_style_contract.py 为共享定义。

## 表格
新表明确列网格，宽度不超过正文。表格对象居中；所有单元格水平、垂直居中，首行/左右缩进清零，重复表头、禁止单行跨页。长内容通过列宽和换行处理。
默认深蓝1F4E79表头、白色加粗字，正文白底黑字，B7C9D6细边框。新表不得继承旧表隐藏合并、残留段落或错误底色。
状态色可用：满足E2F0D9、不满足F4CCCC、暂不能判定FFF2CC、未测试FCE4D6。颜色不能代替状态文字。局部修订保留已有配色。
改焊前后对比表遵循[改焊对比规范](rework-comparison-style.md)：状态列、改焊后浅蓝在前、改焊前浅红灰字在后、接口列白底。
四类正式状态仅“满足、不满足、暂不能判定、未测试”。已有测量但缺判定条件时用“暂不能判定”。

## 图片和验收
默认图宽15.3 cm（范本最常用宽度）；按比例、文字清晰度调整，不超过正文宽度，不强制同高。改焊复测更新区域的图统一高9 cm、宽按原生比例（2250×1500 对应13.5×9 cm，导出规则见改焊对比规范）。仅选需要的正式结果图。
图片居中，紧跟“图N 接口：图像内容”，新图采用纯文字编号；局部编辑保留现有编号及未触及的SEQ域；图片和题注同页，题注不显示源文件名、路径、内部编号。
内部 figure_manifest.csv 用于逐图核对，文末数据溯源附录按 data-traceability.md 必设。默认只交付DOCX，PDF和页面图用于内部检查。
新建报告检查本契约和内容。局部修改的全局格式差异仅供参考，必须对比授权范围外的文字、图片、表格、字段和样式，禁止因此整体标准化。
Word字段刷新后检查最终输出副本并只读渲染逐页查看。模板只含明确占位内容和干净表格，无旧测量、旧图片、批注或修订；参考报告保持原样。
