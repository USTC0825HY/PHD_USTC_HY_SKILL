# 改焊前后对比表规范

权威范本：`02_Test_Reports_测试报告/02_jiaqiang/电性加强件 SZSD_YCQD_20260927.docx`（AD2208 带宽表 JG15 两行为标准行）。适用于加强件与后续鉴定件报告中一切含改焊前后数据的指标表。

历史接口清单仅适用于其注明批次；当前报告已核实新增复测优先，不自动恢复旧版删除行。

## 结构

- 接口列后增加状态列，列名用`状态`或`焊接情况`；两级表头（如 DA766 码值表）时状态列在表头两行间纵向合并（vMerge）。
- 行序固定：改焊后行在前，改焊前行在后；每个接口一组。
- 未复测/未改焊接口单行，状态写`改焊前`或`—`，无底纹；其数值为该接口现有唯一口径，不得当作改焊后结果。
- 未复测接口是否展示按各表既定口径执行，不得凭空恢复已删除的行：AD2208 ILA 高频噪声表（20260927 定稿口径）只列复测接口（JG15/JG19/JG22），未复测接口（JG17/JG24）不列行、不配结果图，结果说明以"未复测，不列结果"一句带过；其余表（如 DA766 输出电压/噪声）维持单行`—`惯例。改动前先确认该表当前状态。
- 接口列纵向合并（蓝本=0927 带宽表）：改焊后行接口格 `vMerge restart` 只显示一次接口名（白底），改焊前行接口格 `vMerge` 延续（空、不可再写接口名）。禁止在接口列重复接口名或使用`（改焊前）`后缀——改焊语义由状态列承载。
- 存量后缀/重复名形态在触及该表时一并转换为合并形态；新建表直接按合并样式。

## 底纹与文字（JG15 标准）

- 配对首行全部段落设keepNext，cantSplit仅防单行内拆分；长表允许在配对之间分页。
- 接口列白底；改焊后行状态格+数据格浅蓝 `B8CCE4`（themeFill accent1, tint 66）；改焊前行 `E5B8B7`（themeFill accent2, tint 66）全行灰字 `595959`。
- 存量变体允许保留、不强改：DA766 表状态格不染色、饱和/刻度表接口格也染色。
- 超差格：改焊对比表内不用深红 `D99594`，行底纹优先、超差数值加粗；非对比表可保留 D99594。
- 公式格（k/b）用两个段落（k 段 + b 段）防中间折行；禁止把上标留到第二段段首。

## 数值与证据纪律

- 改焊前后对比必须同基准、同列口径（如 70 MHz 阻带抑制对 70 MHz，不得拿旧 80 MHz 列数值当改焊前基准）。
- 结果说明中的包络区间取表内实际极值（如五路范围写 -10.00～+10.05 V，不是首行值 -9.941）。
- 方法段采样率/时长/分辨率等参数必须来自对应 run 的 analysis_parameters，禁止从其他器件小节拷贝（0927 曾出现 DA9726 的 2.48MS/s、100s 误拷入 DA766）。
- 噪声折算前核对刻度口径：PICO 总链路检查 run 的 k_adc 是否为该接口当前口径；DAC 直接输出噪声只除以硬件增益、不经码值斜率。
- 黄色高亮等待补数据标记（如“后续补充正确频点”）和用户自加状态标记保留，不当作编辑残留清除。
