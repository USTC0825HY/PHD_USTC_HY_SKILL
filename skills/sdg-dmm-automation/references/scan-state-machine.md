# 逐点扫描状态机

## 状态顺序

```text
PRECHECK
→ SOURCE_CONFIGURED
→ SET_SOURCE
→ SOURCE_SETTLED
→ METER_ARMED
→ MEASURING
→ READING
→ COMMITTED
→ NEXT_POINT
→ COMPLETE
```

异常或用户中止都转入：

```text
STOP_REQUESTED
→ SAVE_EVENT
→ SOURCE_SAFE
→ FAILED / ABORTED
```

## 单点规则

1. 根据码值计划计算目标电压。
2. 设置源电压并等待`*OPC?`。
3. 查询源回读，确认DC模式、输出状态、负载显示和电压误差在容差内。
4. 以单调时钟按目标周期调度，只等待扣除设置/回读/测量后的剩余时间；超期记录，禁止跳点或省略测量。
5. 向万用表发送`INIT`、`*TRG`，再读取`FETC?`。
6. 检查读数有限性、量程和错误队列。
7. 在同一事务中保存测量值、源回读、设备身份和点间隔。
8. 事务提交成功后才允许设置下一点。

## 断点恢复

- 以SQLite中已提交的`sequence_id`为恢复边界。
- 检查源和万用表的型号、序列号、资源地址、配置、映射上下限、更新频率和码值计划摘要。
- 已提交点不得重复测量。
- 在设置源后但数据库提交前崩溃，当前点必须重新测量。
- 提交后但ACK或进度更新前崩溃，只补充状态，不重复测量。

## 时间与自动调零

- 更新频率是目标点间隔的倒数，不是硬实时保证；报告实际间隔及超期。
- 万用表采用单次BUS触发，不使用持续自由采集替代逐点事务。
- SDM4065A持续自动调零由配置完成，不在每4096点强制调零。
- 34470A按项目配置执行周期单次调零；调零期间暂停改变源电压。
