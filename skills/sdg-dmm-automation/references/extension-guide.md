# 新仪器与新项目扩展指南

## 接入新的6½位或7½位数字万用表

1. 读取官方远程控制手册，确认DCV配置、量程、NPLC、输入阻抗、自动调零、触发和读取命令。
2. 建立独立驱动类，不直接复制其他型号的命令字符串。
3. 用`*IDN?`确认型号和固件；记录固件差异，不按序列号选择驱动。
4. 为每个回读参数建立严格校验；未知或不支持的参数应停止，而不是自动降级。
5. 保持统一`measure_voltage`契约，至少支持单次BUS触发或明确声明采用其他测量边界。
6. 增加Fake VISA测试：成功配置、命令顺序、错误、非数值、过量程、超时和多设备发现。
7. 只有完成设备规格、校准和实机重复性评估后，才讨论`qualification_eligible`。

## 接入新的信号源

1. 明确DC输出命令、通道前缀、负载模式、输出开关、回读和完成同步命令。
2. 将目标电压限制在设备和负载共同允许的范围内。
3. 配置时先关闭输出，设置DC和负载，再按用户授权决定是否开启输出。
4. 每次改值都等待完成并回读；回读不一致时停止扫描。
5. 实现0 V后关闭输出的安全路径，并在源设置异常时继续尝试关闭输出。

## 接入新项目

至少新增：

- 仪器配置组和内部型号值；
- GUI/CLI映射；
- 身份与配置快照字段；
- Fake VISA测试；
- 原始数据和manifest字段；
- 结果资格策略；
- 实机检查命令和操作记录。

保持现有数据格式兼容时，新增字段放在CSV末尾；不要修改已有字段名或SQLite既有列含义。
