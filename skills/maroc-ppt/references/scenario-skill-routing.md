# MAROC PPT Scenario Skill Routing

Keep `maroc-ppt` as the shared MAROC style, template, typography, technical-figure, wording, and QA skill.

Use these newer scenario skills for deck structure:

- `maroc-ppt-debug-report`: one focused debug problem or bring-up blocker.
- `maroc-ppt-progress-summary`: overall progress, timeline, completed work, risks, next plan.
- `maroc-ppt-group-meeting`: Chinese lab/group meeting report.
- `academic-paper-analysis-ppt`: paper-reading and literature-analysis presentation.
- `maroc-evidence-ppt-sync`: evidence-to-claim filtering before slide writing.
