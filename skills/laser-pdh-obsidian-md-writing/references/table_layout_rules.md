# Table Layout Rules

适用范围：`Laser_PDH_Study` 正式笔记中的 Markdown 表格排版、宽表修复和长文本表重排。

## 修复边界

- 跳过 `01_Raw` 原始资料和 `_旧版.md` 备份。
- 不改数值、证据编号、图片路径、文件名、`needs_check` 含义和结论口径。
- 优先修复阅读体验；不为了降低宽表计数而拆散本来适合比较的数值表。

## 优先避免的表格

以下表格在 Obsidian 预览中容易被压成竖排，应改成字段清单或卡片：

- 截图说明表：`截图 | 来源 | 页码/位置 | 功能块 | 测试关注点 | 易错点`。
- 器件解释表：器件位号、型号、供电、输入、输出、关键参数、使用原因等长字段。
- 输入/输出接口清单：连接器、信号名称、来源/目标、信号类型、带宽、证据、`needs_check`。
- 测试任务表：任务、模块、接口、仪器、判据、记录要求等长字段。
- 故障排查表：现象、来源、诊断、处理建议。
- 资料来源表：含长路径、抽取副本路径、证据边界和引用定位。

## 可以保留的表格

以下表格适合保留，并依赖 `laser-pdh-note` CSS 横向滚动查看：

- 数值对比表、指标表、频谱/噪声统计表。
- 短字段矩阵，例如板卡-环路矩阵、信号矩阵。
- 记录模板和测试记录空表。
- 字段短、行列关系比正文叙述更清楚的工程对照表。

## 转换格式

长文本说明表统一改为条目字段清单：

```markdown
#### 1. 条目标题
- 字段一：原单元格内容
- 字段二：原单元格内容
- needs_check：原核查说明
```

截图说明表应放在图片附近：

```markdown
![截图说明](path/to/image.png)

- 来源：文件名或 PDF 名。
- 页码/位置：页码、图号或段落。
- 功能块：截图对应的电路块。
- 测试关注点：测试时需要检查的节点或指标。
- 易错点：易混淆点或 `needs_check`。
```

故障排查表改为排查卡片：

```markdown
#### 现象名称
- 现象：观察到的问题。
- 可能来源：电路、仪器、固件、线缆或参数来源。
- 诊断方法：建议先做的验证。
- 处理建议：下一步动作。
```

## CSS 配合

`<obsidian_vault_root>/.obsidian/snippets/laser-pdh-study.css` 应让 `.laser-pdh-note table` 支持横向滚动，单元格正常换行，代码、路径、网络名不被强制拆开。修改表格排版后运行审计脚本，查看 `TABLE_*` 计数和原有 CSS/截图/Mermaid/LaTeX 检查。
