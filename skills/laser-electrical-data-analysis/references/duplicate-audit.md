# 重复数据与归档内容审计

独立于数值分析。显式指定 source root 和源树外输出目录；先估计范围与体积，默认不自动遍历其他盘。工具纯读取源文件，不指定删除件。

## 内容审计

audit_duplicates.py：大小分组预筛，同大小候选流式 SHA-256，全哈希相同才归组；哈希期间大小/mtime 改变则报错。输出重复文件清单、B类标注、分区汇总、baseline_snapshot.json。冗余字节为每组(n−1)×大小的理论值；B类与多分区共享组不能直接转成释放量。

同目录不同名同内容为 B 类：档位文件、PSD_ASD 双名、改名副本等可能含语义，只标注不删。跨目录组也只是候选；raw/instrument、正式结果包、规范树等保留优先级须结合该次报告引用逐条裁决，不能总按时间早晚选择。

compare_archive.py：用已安装 bsdtar/tar 列全部成员，拒绝不安全路径、链接、重复/大小写冲突成员，整包解压至新的任务子目录。逐成员按大小和 SHA-256 与库内文件比较；所有成员可读、全部有匹配、源库扫描完整且归档自身哈希稳定才记 all_members_duplicate=true。错误和独有成员阻止完全重复结论。归档工具输出编码默认取当前系统locale并写入报告，可用--encoding显式覆盖；解码失败记失败，不静默丢弃中文名。

## 清理是单独动作

只有当前任务明确授权了清理范围及保留规则，才编制清理计划。执行前双端重算哈希→先写 cleanup_journal→操作→记录结果；删后 baseline/post_snapshot 按同一范围对账文件数与字节，并逐条复检保留件。检测到孤本、变化、不可访问或账差立即停止相关操作。优先按工作区清理规则隔离高风险项；过去的“直删”授权仅属于过去任务。

未运行真实删除时只交付审计，不写“已释放空间”。库内结构调整与重复清理分别记账。
