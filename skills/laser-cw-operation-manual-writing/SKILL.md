# 513 CW 操作手册撰写

用于 `03_Operation_Guide_操作说明与流程图` 下的器件、链路和板卡操作手册。创建手册或调整全篇格式前，读取 [手册格式与写法契约](references/current-cw-manual-contract.md)。

## 操作范围

- 以用户指定范围和最新文件为准。局部格式修改直接处理最新 DOCX，不用旧脚本重新生成整本手册，不覆盖用户改过的文字、截图和表格。
- ILA 专用手册只写接口、通道、探针、显示方式、采集步骤和异常处理；不强加 VIO 设置、完整测试模式或理论介绍。
- 涉及 VIO 时，写清选哪个窗口、设置哪个具体信号、写什么值、何时提交、在哪个沿触发、看什么回读、结束后恢复什么。
- 只核对影响操作的技术疑点。探针名称、接口和码值来自本次目标工程及配套 LTX；旧手册可以提供线索，不能代替当前工程。技能不保存会过期的探针编号和发布结论。

## 操作对象使用具体信号名

- 面向使用者的手册正文、步骤、表格、触发条件和异常排查，使用当前RTL及配套LTX中的具体信号名，不用 `probeN`、`probe_inN`、`probe_outN`、`outN` 或 `inN` 编号代替操作对象，也不附带编号对照表。
- 写“将 `dds2_adc_amp_enable` 置1”，不要写“将out13置1”；写实际数据、有效、请求、更新和错误信号名。多个实例存在同名信号时，补足层级；较长的公共层级可在表前统一说明。
- LTX显示名的后缀、总线名和位选须按当前文件保留。若状态打包在旧名称的总线中，写实际 `总线名[位]` 并解释含义，不虚构独立可见信号。多通道可说明真实前缀替换规则，并给出具体通道示例。
- 交付前检查正文和表格是否残留编号式操作说明；同时确认替换后的名称确实能在当前配套LTX中定位。只有用户明确要求底层接线或编号审计时，才在该专项资料中列编号映射，操作手册仍以信号名为主。

## 固定格式

- **中文保留现有模式。** 继承用户指定模板或当前手册的中文字体、字号、加粗、页面与间距。修订时不把中文统一替换为另一字体。
- **西文统一 Times New Roman。** 字母、数字、单位、路径、信号名和控制字均适用，覆盖题名、标题、正文、表格、页眉、页脚和编号。分别设置西文与东亚字体属性；不得通过统一替换整个 run 的字体改变中文显示。
- **表格内所有内容始终水平居中、垂直居中。** 表头、正文、长信号名、多行说明、合并单元格和新增行都适用，没有长文本左对齐的例外。列宽和换行优先于缩小字号；表外正文不受此规则影响。
- 使用自动章节编号 `第1章 / 1.1 / 1.1.1`。标题样式共享同一多级列表，标题段落不另设直接编号覆盖。操作步骤使用独立列表，每组从 `1.` 开始，并显式设置起始值。

## 文字与技术说明

用简短的“选择、设置、写入、触发、观察、恢复、停止”说明动作。保留准确的位宽、进制和边沿，不写空泛的总结、写作过程、核查过程、SHA/哈希或打磨报告。交付说明只说改了什么和仍影响操作的待确认项。

接口表按确认的板端接口与逻辑通道填写，给出可定位的完整层级；可用公共前缀加逐路索引减少重复。不能从 `hw_vio_N` / `hw_ila_N` 的显示编号推测通道或连接器。无法确认的关键项写简短的“待确认”。

VIO 回读与 ILA 波形表示 FPGA 内部逻辑，不代替外部电压、连线和器件动作测量。使能、停止、重新初始化和关断是否真的生效，需要核对代码，而不是按信号名称推断。固件在编写期间更新时，交付前重新检查相关映射。

## 修改与验证

1. 检查最新文件及 Word 锁文件，先备份。未占用的文件可按授权原名更新；被占用的文件另存为 `<原名>_格式修订.docx`，不覆盖、不移动打开的原件。
2. 使用文档技能完成编辑和逐页渲染检查。字号、强调、图片、字段、超链接和非目标内容应保留。
3. 格式修订使用 `scripts/normalize_manual_format.py INPUT OUTPUT`；只检查使用 `scripts/normalize_manual_format.py INPUT --check`。脚本直接修改 DOCX 包，统一西文字体及表格居中，保留东亚字体配置。输出必须为新文件。
4. 编号检查使用 `scripts/repair_manual_heading_numbering.py INPUT --check`。只有确实需要修复编号时才使用其另存模式；已有正常编号的格式修订不得重建列表。
5. 检查全部页面的居中效果、长信号换行、表格跨页、截图、页眉页脚和异常空白。自动检查通过不能代替页面检查。
6. 正式 DOCX 放回手册目录；不额外交付 PDF、渲染图片或检查日志。保留备份，清理本次可再生预览缓存。
