# Skill 全盘审计摘要（2026-07-26）

## 范围与口径

本次扫描覆盖本机已发现的 Codex、CC Switch、Claude marketplace、插件缓存和离线备份
中的 `SKILL.md`。治理仓库只纳入用户直接维护的两个来源层，系统内置 Skill、已启用
插件缓存和可重新下载的依赖不作为规范副本。

全盘共发现 1,731 个物理 `SKILL.md`。其中用户管理层有 127 个物理副本，对应 95 个
逻辑名称；按文件内容校验后，32 组重复副本内容完全一致，另有 10 个符号链接桥接。
归并过程没有静默选择内容冲突的副本。

## 归并结果

- 逻辑 Skill：95；
- 顶层规范目录：88；
- 保留的嵌套子 Skill：7；
- 功能主体：FPGA/硬件 43、学术研究 16、PPT/视觉表达 14、办公文档 6、
  Laser/PDH 5，其余 11；
- 自动补齐缺失 `agents/openai.yaml`：9 个；
- 统一规范触发提示：95 个；
- 排除缓存、嵌套 Git 仓库和依赖目录：13 项。

## 来源冲突

扫描发现 `imagegen`、`openai-docs`、`skill-creator` 和 `pdf` 四个名称同时出现在
用户目录与系统/插件来源中。治理仓库采用用户维护副本优先，系统和插件副本保持外部
依赖，不复制进入仓库。升级插件时应重新比对这些名称，避免系统更新反向覆盖个人版本。

## 风险结论

- 结构、注册表哈希与密钥扫描均通过；
- 95 个 Skill 均通过 `skill-creator` 官方快速校验；
- 75 个文件含本机绝对路径或环境绑定示例，适合私有备份，但公开前应参数化；
- 70 个 Skill 暂无充分的再发布许可证证据；
- 指定 GitHub 仓库在发布前检查时为 Public，因此完整内容尚不满足上传门槛。

详细机器可读结果见 `registry/skills.json`、`reports/preflight.json` 和
`reports/official-quick-validate.json`。
