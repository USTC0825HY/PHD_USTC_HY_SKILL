# 图像与媒体

处理图像、截图、照片、语音、转写及媒体产物。

按媒体输入输出选择技能，并保留原始文件。

本类共 **7 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [hatch-pet](../../../skills/hatch-pet/SKILL.md) | 制作、修复和打包 Codex 动画宠物图像资产。 |
| [imagegen](../../../skills/imagegen/SKILL.md) | 根据描述生成图像或对现有图像做编辑。 |
| [photo-person-filter](../../../skills/photo-person-filter/SKILL.md) | 依据参考照片筛选包含指定人物的图片。 |
| [ppt-club-recruiting](../../../skills/ppt-maker/subskills/club-recruiting/SKILL.md) | 制作面向社团招新和活动推广的 PPT。 |
| [screenshot](../../../skills/screenshot/SKILL.md) | 截取桌面、窗口或指定屏幕区域。 |
| [speech](../../../skills/speech/SKILL.md) | 生成语音旁白、无障碍朗读或批量音频。 |
| [transcribe](../../../skills/transcribe/SKILL.md) | 将音频或视频语音转为文本，可区分说话人。 |

`ppt-maker` 的场景子 Skill 保持在其 `subskills/` 目录，随父技能装载，不作为独立顶层目录复制。
