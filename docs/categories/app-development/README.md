实现 ASP.NET、ChatGPT App、网页游戏和 WinUI 应用。

按应用平台进入对应工程流程。

本类共 **4 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [aspnet-core](../../../skills/aspnet-core/SKILL.md) | 开发和审查 ASP.NET Core、Blazor 与 .NET Web 应用。 |
| [chatgpt-apps](../../../skills/chatgpt-apps/SKILL.md) | 开发含 MCP 服务和组件界面的 ChatGPT Apps SDK 应用。 |
| [develop-web-game](../../../skills/develop-web-game/SKILL.md) | 迭代网页游戏，并用浏览器测试操作与画面。 |
| [winui-app](../../../skills/winui-app/SKILL.md) | 用 C# 和 Windows App SDK 开发 WinUI 桌面应用。 |
