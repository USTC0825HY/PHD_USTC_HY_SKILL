# Laser/PDH 与精密测量

覆盖 Laser/PDH 电测、CW 板卡、仪器协同和操作报告。

本类共 **13 个逻辑 Skill**。当前装载以 `profiles/codex.json` 为准；历史保留项不代表当前仍在使用。

| [laser-schematic-screenshot-repair](../../../skills/laser-schematic-screenshot-repair/SKILL.md) | 修复或重裁 Laser/PDH 原理图截图供笔记使用。 |
| [laser-test-report-writing](../../../skills/laser-test-report-writing/SKILL.md) | 按紧凑新建、局部修订或正式模板模式写报告，检查越界修改、新增缺陷和图片身份。 |
