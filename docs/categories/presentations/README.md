# 演示文稿与视觉表达

制作与检查学术汇报、项目演示和可编辑图示。

按内容组织选研究或项目流程，再用制作工具完成排版与导出。

本类共 **15 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [academic-paper-presentation](../../../skills/academic-paper-presentation/SKILL.md) | 制作或审查论文、课程和答辩等学术 PowerPoint。 |
| [academic-pptx](../../../skills/academic-pptx/SKILL.md) | 规划学术报告内容结构，说明研究动机、方法与证据。 |
| [aut-sci-ppt](../../../skills/aut-sci-ppt/SKILL.md) | 将论文 PDF 或结构化文本整理为答辩与研讨会 PPT。 |
| [auto-visio-helper](../../../skills/auto-visio-helper/SKILL.md) | 规划、生成和修改可编辑的 Visio 科研图示。 |
| [figma](../../../skills/figma/SKILL.md) | 读取 Figma 设计上下文、截图和资产，供实现使用。 |
| [figma-implement-design](../../../skills/figma-implement-design/SKILL.md) | 将 Figma 设计节点转成与设计一致的界面代码。 |
| [guizang-ppt-skill](../../../skills/guizang-ppt-skill/SKILL.md) | 生成杂志风横向翻页的网页演示文稿。 |
| [ppt-course-presentation](../../../skills/ppt-maker/subskills/course-presentation/SKILL.md) | 制作小组作业和课堂展示 PPT。 |
| [ppt-customer-story](../../../skills/ppt-maker/subskills/customer-story/SKILL.md) | 制作包含背景、方案和成效的客户案例 PPT。 |
| [ppt-english-lesson](../../../skills/ppt-maker/subskills/english-lesson/SKILL.md) | 制作英语课堂讲解和练习课件。 |
| [ppt-maker](../../../skills/ppt-maker/SKILL.md) | 从主题或材料生成可编辑的结构化 PPT。 |
| [ppt-project-intro](../../../skills/ppt-maker/subskills/project-intro/SKILL.md) | 制作项目方案、产品介绍或阶段复盘 PPT。 |
| [research-defense-ppt](../../../skills/research-defense-ppt/SKILL.md) | 组织科研答辩 PPT 与讲述脚本。 |
| [slides](../../../skills/slides/SKILL.md) | 创建和编辑可验证布局的 PPTX 演示文稿。 |
| [zz-academic-paper-ppt](../../../skills/zz-academic-paper-ppt/SKILL.md) | 制作和检查中文学术论文汇报 PPTX。 |

`ppt-maker` 的场景子 Skill 保持在其 `subskills/` 目录，随父技能装载，不作为独立顶层目录复制。
