# 云部署与 Git 工作流

处理站点部署、GitHub 审查与 CI 故障。

按托管平台选部署技能；PR 评论与 CI 使用独立流程。

本类共 **6 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [cloudflare-deploy](../../../skills/cloudflare-deploy/SKILL.md) | 将应用部署到 Cloudflare Workers、Pages 等服务。 |
| [gh-address-comments](../../../skills/gh-address-comments/SKILL.md) | 核对并处理当前 GitHub PR 的审查意见。 |
| [gh-fix-ci](../../../skills/gh-fix-ci/SKILL.md) | 读取 GitHub Actions 检查日志并修复 PR CI 失败。 |
| [netlify-deploy](../../../skills/netlify-deploy/SKILL.md) | 使用 Netlify CLI 部署或连接网站工程。 |
| [render-deploy](../../../skills/render-deploy/SKILL.md) | 分析项目并部署到 Render，生成部署配置。 |
| [yeet](../../../skills/yeet/SKILL.md) | 按明确要求一次完成暂存、提交、推送和创建 PR。 |
