# MATLAB

编写、审查、测试和迁移 MATLAB 代码。

本类共 **6 个逻辑 Skill**。当前装载以 `profiles/codex.json` 为准；历史保留项不代表当前仍在使用。

| Skill | 主要功能 |
|---|---|
| [matlab-clean-code](../../../skills/matlab-clean-code/SKILL.md) | 按清晰命名、单位和注释整理 MATLAB 代码。 |
| [matlab-modernize-code](../../../skills/matlab-modernize-code/SKILL.md) | 按目标版本迁移 MATLAB API 或语法，保持数值行为与输入契约。 |
| [matlab-review-code](../../../skills/matlab-review-code/SKILL.md) | 依据证据审查功能、数值、兼容性和性能问题，区分错误与风格建议。 |
| [matlab-testing](../../../skills/matlab-testing/SKILL.md) | 沿用项目测试形式，按误差来源选择容差并核对实际执行层。 |
| [matlab-validate-function-arguments](../../../skills/matlab-validate-function-arguments/SKILL.md) | 设计或审查输入校验，按项目选择 arguments 或既有校验方式。 |
| [matlab-write-help](../../../skills/matlab-write-help/SKILL.md) | 按项目语言与文档风格编写帮助，只描述源码支持的行为。 |
