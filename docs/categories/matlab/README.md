# MATLAB

编写、审查、测试和迁移 MATLAB 代码。

先用审查定位问题，再选现代化、参数校验、帮助文本或测试技能。

本类共 **6 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [matlab-clean-code](../../../skills/matlab-clean-code/SKILL.md) | 按清晰命名、单位和注释整理 MATLAB 代码。 |
| [matlab-modernize-code](../../../skills/matlab-modernize-code/SKILL.md) | 替换 MATLAB 已弃用函数和旧式代码模式。 |
| [matlab-review-code](../../../skills/matlab-review-code/SKILL.md) | 审查 MATLAB 代码质量、性能和规范性。 |
| [matlab-testing](../../../skills/matlab-testing/SKILL.md) | 编写 MATLAB 单元、参数化和 GUI 测试。 |
| [matlab-validate-function-arguments](../../../skills/matlab-validate-function-arguments/SKILL.md) | 用 arguments 块约束 MATLAB 函数输入。 |
| [matlab-write-help](../../../skills/matlab-write-help/SKILL.md) | 为 MATLAB 函数、类和脚本编写标准帮助文本。 |
