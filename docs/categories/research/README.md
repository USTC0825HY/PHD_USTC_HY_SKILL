# 学术研究与论文

支持选题、文献、研究设计、论文结构和投稿检查。

本类共 **17 个逻辑 Skill**。当前装载以 `profiles/codex.json` 为准；历史保留项不代表当前仍在使用。

|---|---|
| [academic-paper-analysis-ppt](../../../skills/academic-paper-analysis-ppt/SKILL.md) | 把论文、图表和实验结果整理成可讲述的中文论文分析汇报。 |
| [academic-paper-writing](../../../skills/academic-paper-writing/SKILL.md) | 依据实验材料撰写和检查论文、课程报告及 LaTeX/PDF 文稿。（远端历史保留，未在当前个人技能目录安装。） |

| [figure-designer](../../../skills/figure-designer/SKILL.md) | 设计技术论文中的动机示例、方案概览和评估图。 |
| [hypothesis-generation](../../../skills/hypothesis-generation/SKILL.md) | 提出可检验的研究假设、替代解释和判别实验。 |
| [idea-evaluator](../../../skills/idea-evaluator/SKILL.md) | 按价值、可行性和研究阶段评估初步研究想法。 |

| [tech-paper-template](../../../skills/tech-paper-template/SKILL.md) | 组织技术论文的研究背景、挑战、方法与证据。 |
