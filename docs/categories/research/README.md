# 学术研究与论文

支持选题、文献、研究设计、论文结构和投稿检查。

先明确研究问题与证据，再选写作、图表或审稿技能。

本类共 **17 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [academic-paper-analysis-ppt](../../../skills/academic-paper-analysis-ppt/SKILL.md) | 把论文、图表和实验结果整理成可讲述的中文论文分析汇报。 |
| [academic-paper-writing](../../../skills/academic-paper-writing/SKILL.md) | 依据实验材料撰写和检查论文、课程报告及 LaTeX/PDF 文稿。 |
| [benchmark-paper-template](../../../skills/benchmark-paper-template/SKILL.md) | 按研究缺口、构建和评估证据组织 Benchmark 论文。 |
| [figure-designer](../../../skills/figure-designer/SKILL.md) | 设计技术论文中的动机示例、方案概览和评估图。 |
| [hypothesis-generation](../../../skills/hypothesis-generation/SKILL.md) | 提出可检验的研究假设、替代解释和判别实验。 |
| [idea-evaluator](../../../skills/idea-evaluator/SKILL.md) | 按价值、可行性和研究阶段评估初步研究想法。 |
| [idea-generation](../../../skills/idea-generation/SKILL.md) | 结合文献检索迭代生成和筛选研究问题。 |
| [intro-drafter](../../../skills/intro-drafter/SKILL.md) | 按研究背景、局限和贡献组织技术论文引言。 |
| [jupyter-notebook](../../../skills/jupyter-notebook/SKILL.md) | 创建和修改用于实验、探索及教程的 Jupyter Notebook。 |
| [novelty-assessment](../../../skills/novelty-assessment/SKILL.md) | 通过多轮文献检索评估研究想法的新颖性。 |
| [ppt-thesis-defense](../../../skills/ppt-maker/subskills/thesis-defense/SKILL.md) | 制作强调研究问题和数据证据的答辩 PPT。 |
| [qu-ai-wei](../../../skills/qu-ai-wei/SKILL.md) | 在保留事实的前提下改善简体中文文稿表达。 |
| [research-ideation](../../../skills/research-ideation/SKILL.md) | 用结构化问题寻找研究缺口和选题方向。 |
| [scientific-brainstorming](../../../skills/scientific-brainstorming/SKILL.md) | 基于证据开展科研方案构思和比较。 |
| [systematic-literature-review](../../../skills/systematic-literature-review/SKILL.md) | 检索并综合多篇论文形成系统性文献综述。 |
| [tech-paper-template](../../../skills/tech-paper-template/SKILL.md) | 组织技术论文的研究背景、挑战、方法与证据。 |
| [vibe-research-workflow](../../../skills/vibe-research-workflow/SKILL.md) | 组织 AI 辅助研究中的代码、图示和写作流程。 |
