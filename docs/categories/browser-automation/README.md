# 浏览器与自动化

通过可观察的浏览器会话执行或调试页面任务。

按一次性浏览器操作或持续交互调试选择对应技能。

本类共 **2 个逻辑 Skill**。详情以各技能的 `SKILL.md` 为准。

| Skill | 主要功能 |
|---|---|
| [playwright](../../../skills/playwright/SKILL.md) | 通过终端控制浏览器进行页面操作和测试。 |
| [playwright-interactive](../../../skills/playwright-interactive/SKILL.md) | 在持续浏览器会话中调试网页和 Electron 界面。 |
