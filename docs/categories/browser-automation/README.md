本类共 **2 个逻辑 Skill**。当前装载以 `profiles/codex.json` 为准；历史保留项不代表当前仍在使用。

| Skill | 主要功能 |
|---|---|
| [playwright](../../../skills/playwright/SKILL.md) | 通过终端控制浏览器进行页面操作和测试。（远端历史保留，未在当前个人技能目录安装。） |
| [playwright-interactive](../../../skills/playwright-interactive/SKILL.md) | 在持续浏览器会话中调试网页和 Electron 界面。 |
